# 月別12週資料の統一用語

2026-09-19の教員指摘に対応した、この実験の用語表。1週間は168時間、15分区間は672個。別の時間解像度・実験には無条件で適用しない。

| 正式名称 | 定義・計算 | 単位 |
|---|---|---|
| 受電電力 | 系統から購入する電力の各15分平均値 P(t) | kW |
| 受電ピーク | 1週間の672個のP(t)の最大値 | kW |
| 週間平均受電電力 | 週間購入電力量÷168時間。受電ゼロの区間を含む | kW |
| 週間購入電力量 | Σ P(t)×0.25時間、tは週間の全672区間 | kWh、またはMWh |
| 日別購入電力量 | 当該日の96区間のΣ P(t)×0.25時間 | kWh |
| 超過判定値 | 超過ペナルティの計算基準200 kW | kW |
| 超過電力量 | Σ max(P(t)−200,0)×0.25時間。週間集計なら全672区間 | kWh |
| 超過時間 | P(t)>200 kWである区間数×0.25時間 | h |
| 受電時間 | P(t)>1 kWである区間数×0.25時間 | h |
| 購入電力費 | 週間購入電力量×30円/kWh | 円 |
| 超過ペナルティ | 週間の超過電力量×500円/kWh | 円 |
| 週間費用 | 車両使用費・購入電力費・燃料費・CO₂費用・超過ペナルティの合計 | 円、または万円 |

受電ピーク区間は受電ピークを記録した15分区間。同値が複数ある場合は「一例」と記載する。瞬時最大電力はこの15分データからは分からない。超過判定値は受電ピークでも物理的受電上限でもない。500円/kWhはモデル係数であり、実際の契約料金としての妥当性は未確認。

超過時間の実集計では、浮動小数の誤差を除くため1e-6 kWの許容差を使う。超過電力量はmaxによる積算であり、時間集計の閾値をそのまま流用しない。

「最大15分平均受電電力」「ピーク電力」「最大電力」を受電ピークの別名として混在させない。「平均電力」「購入量」「系統購入量」など、対象や期間の省略も避ける。季節集計は「週間購入電力量の平均（選択3週）」とし、「週間平均受電電力」と混同しない。
