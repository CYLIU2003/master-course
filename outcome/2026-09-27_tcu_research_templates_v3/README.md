# 都市大ブルーの研究スライドテンプレート v3

手動で埋めて使う研究発表・進捗報告テンプレートです。白地に明るい青、16:9、日本語メイリオ／英数字Times New Roman。全34種類に記入式の発表カンペを収録しています。

## v3：中島先生の参考資料を踏まえた導入

提供された `刘承洋_9月発表用.pptx`（表紙日付2025年9月17日）の1〜4ページを表示確認し、特に2〜4ページの説明の流れを参考に導入6枚を改訂しました。v2で未確認だった共有資料の照合は完了しています。反映箇所は [参考資料と反映箇所](参考資料と反映箇所.md) に記録しました。

**迷ったら研究発表スターターを使ってください。** 3・4ページに導入Aを組み込み済みです。冒頭は「表紙 → 構成 → 社会背景・研究背景 → 研究課題・研究目的 → 先行研究」です。

|---|---|---|---|
| A：社会背景から研究目的へ | 行政・政策関係者、研究の必要性を説明する場 | 社会の目標と技術課題 → 未解決の課題と研究目的 | 29・30 |
| B：現場の要請から仮説へ | 実務者・事業者、比較する方法を説明する場 | 現場の要請と制約 → 比較する方法と検証仮説 | 31・32 |
| C：目的から検証方法へ | 研究概要・短い審査説明 | 目的と社会的意義 → 対象モデル・条件・評価 | 33・34 |

1. [導入3パターン](都市大ブルー_導入3パターン.pptx)の1–2枚／3–4枚／5–6枚から1組を選びます。各ペアの用途はノート・レイアウト名・この表で確認できます。
2. Aは研究発表スターターに組み込み済みです。BまたはCを使う場合は、スターターの3・4ページと差し替えてください。同じ内容が重なる「研究目的」「対象システム」「手法」などは発表時間に合わせて整理します。
3. AとBの後は先行研究や方法へつなぎます。Cは研究の全体像を先に示すため、後続のモデル・条件ページは詳細の説明に使います。短い発表では目次を省いても構いません。Cを表紙の直後へ置く場合は、表紙のカンペ末尾を「最初に研究の目的をお伝えします」へ変更します。
4. ［ ］を自分の研究に置換します。目的文は「［対象・条件］における［方法］と［評価量］の関係を明らかにする」を基本にし、必要なら2行へ分けます。補助見出しは不要なら削除できます。
5. 政策・統計は正式名称、発行主体、年、頁を確認して記入します。長いURLや解説はノートへ移します。参考資料から借りたのは構成と文章の型で、政策値・技術上の主張・実験値・図・大学ロゴは転記していません。

## カンペの使い方

PowerPointの通常表示で画面下の「ノート」を開いてください。発表時は発表者ツールでも参照できます。

- **話す内容**：［ ］を埋めると話し言葉になる文章。各ページに合わせて作成。
- **指す場所・間の取り方**：図、表、左右の比較など、説明時の視線の案内。
- **次ページへのつなぎ**：ページ順に合わせて変更する一文。
- **自分用のメモ**：強調語、省略できる説明、想定質問、回答の根拠。
- **記入・編集の補足**：従来の構成ガイド。読み上げ用ではありません。

目安時間は内容により調整してください。初稿で全欄を使う必要はありません。カンペを短くする場合も、比較条件・単位・結論の範囲は残します。

**カンペも引き継ぐ場合は見本ページを `Ctrl+D` で複製してください。** 「新しいスライド」でレイアウトだけを選ぶ操作では、そのページ固有のノートは自動入力されません。その場合は [カンペ雛形一覧](カンペ雛形一覧.md) から対応する文章をコピーできます。POTXを開いて作成した資料には34枚の見本とカンペが入っています。

## 内容を埋める手順

1. 用途に合うスターターを開き、最初に「名前を付けて保存」で自分の発表ファイルを作ります。
2. `［ ］` の中を自分の内容に置き換えます。スライドの下にある「ノート」に、各ページの話す文章・指す場所・つなぎ・書き方を入れています。
3. ページを増やすときは、左のサムネイルを選び `Ctrl+D` で複製します。表・グラフ・配色もそのまま引き継げます。
4. 空の入力欄から作る場合は「ホーム → 新しいスライド」の▼からレイアウトを選びます。既存ページは「ホーム → レイアウト」で変更できます。
5. 表はセルへ直接入力、見本グラフは右クリック →「データの編集」で数値を変更します。系列名、カテゴリ、軸名、単位、注記も同時に更新します。
6. フッターは「挿入 → ヘッダーとフッター → スライド」で研究題目の短縮形を設定します。ページ番号は番号フィールドで、並べ替えに追従します。

**表・グラフは見本スライドの複製が最も簡単です。** 新規レイアウトには表・グラフ用の挿入欄があり、表の行数やデータまで自動入力されるわけではありません。

図を貼るときは、水色の入力欄を選んで内容を挿入するか、不要な入力欄を削除して図を配置します。画像の縦横比は保ってください。図・数式・画像そのものは含めず、配置する場所を用意しています。

## フォントと色

- 日本語：**メイリオ（Meiryo）**。英数字：**Times New Roman**。見出し・本文・テーマ・入力欄に和文／欧文を設定しています。
- 表紙：約43.5 pt、通常タイトル33 pt、本文おおむね22〜25 pt、表18.75〜19.5 pt、グラフ18 pt、出典13.5 pt、フッター12 pt。
- 本文は濃い青 `#173A50`、アクセントは明るい青 `#0098D7`、小見出しは `#0079AD`、淡い背景は `#EDF8FD`。
- 青は東京都市大学のイメージを参考にした独自の配色です。公式の色番号を示すものではなく、大学公式テンプレートや公式ロゴの複製ではありません。

Noto Sans JPを使いたい場合は、「表示 → スライドマスター → フォント → フォントのカスタマイズ」で日本語側を変更し、既存文字は「フォントの置換」でメイリオをNoto Sans JPへ置換してください。Times New Romanは残します。グラフ内の文字も個別に確認してください。

他の資料から文章を貼り付けるときは「テキストのみ保持」を選ぶと書式が混ざりにくくなります。数式は `Alt+=` でPowerPoint標準の数式を挿入できます。組版数式にはPowerPoint側の数式用フォントが使われる場合があります。

## 端的な研究スライドにする目安

- 設定を説明するページは短い題名、結果ページは根拠のある結論を1文で置きます。
- 本文は要点を絞り、細かい説明・導出はノートや補足に移します。収まらないときは、文字を小さくする前にページを分けます。
- 比較する図は、対象期間・軸範囲・色・単位をそろえます。凡例や条件は省略しません。
- 進捗報告では「作業したこと」に加え「新たにわかったこと」「未確認のこと」を示します。
- 見本グラフの数値は仮データです。実際の結果へすべて置き換えた後で、仮データの注記を削除します。

EVバス研究の月別比較では、各月の選定週を明記し、12代表週の結果を月平均・季節一般・年間全体の結果と読み替えないでください。計算完了、物理的実行可能性、会計整合、最適性、研究採用は別の確認事項です。ここに研究の結論や実験値は入れていません。
