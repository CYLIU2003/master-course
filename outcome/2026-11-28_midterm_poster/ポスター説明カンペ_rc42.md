## 1分版（足を止めてくれた人向け）

1. 〔1．背景〕 運輸部門は日本のCO₂の約2割を出しています。路線バスも電動化が進んでいますが、一度には置き換えられないので、しばらくは燃料バスと一緒に走らせます。
2. 営業所で電気バスを同時に充電すると、受電電力が大きくなります。受電電力が大きいと、基本料金も上がります。
3. 〔2．手法〕 そこで、どの便を電気バスに任せるか、いつ何kWで充電するかを最適化で決めました。
4. 〔図3〕 東急バスの渋21〜23系統、1週間1,704便で計算しました。ほとんどのケースで、電気バスが9割以上の便を担当しました。
5. 〔表3・図4〕 ただし、**受電上限は高いほど安いわけではありません**。基本料金が上限に比例して増えるからです。今回の条件では、冬に超過が出ない400 kWが目安で、900 kWより週に約24万円安くなりました。
6. 〔図6〕 来年3月の電気学会全国大会で発表します。

## 3分版（じっくり聞いてくれる人向け）

### ① 背景と目的（30秒）〔1．背景と目的〕

- 運輸部門は日本のCO₂の19.3%を出しています。2050年カーボンニュートラルに向けて、路線バスも電動化が進んでいます。
- 電気バスは一度に置き換えられないので、当面は燃料バスと併用です。
- 電気バスは営業所でまとめて充電します。同時に充電すると、受電電力が大きくなります。
- 目的は、**受電電力を抑えつつ、今の時刻表のまま、電動化でCO₂を減らす**ことです。

### ② 手法（50秒）〔2．手法、電気代の式、図1、表1〕

- 決めるのは2つです。
  - 各便を電気バスと燃料バスのどちらが担当するか
  - 電気バスをいつ・何kWで充電するか
  
  時刻表の便はすべて運行します。
- 目的関数は1週間の総費用で、車両使用費・電気代・燃料代・CO₂の費用を足したものです。CO₂の費用は計画の重みとしてだけ使い、結果の費用には入れていません。
- 〔電気代の式〕 電気代は東京電力の高圧料金の形にしました。項は3つあります。
  1. 電力量料金：17.43円/kWh
  2. 基本料金：受電上限 P × 2,530円/kW・月 × 0.85 を、週の額に直したもの
  3. 上限を超えた電力：500円/kWh（仮の値）
  
  基本料金は P だけで決まる定数なので、最適化には入れず、結果に足しています。
- 〔図1〕 計算は4段階です。
  1. 便を割り当てる
  2. 前日に15分ごとの充電を計画する
  3. 実際の日射に合わせて、1時間ごとに計画し直す
  4. 実際に走らせた結果で、費用とCO₂を数える

### ③ ケース（15秒）〔3．ケーススタディ、図2、表2〕

- 東急バス渋21〜23系統、弦巻営業所、1週間1,704便です。
- 設備は、電気バス35台・燃料バス25台、90 kWの充電器10基、太陽光1,000 kW、蓄電池6,000 kWhです。
- 受電上限を90・200・400・900 kWの4通りにし、冬・春・夏の代表週と組み合わせた12ケースです。

### ④ 結果（50秒）〔4．結果〕

- 〔図3〕 電気バスは11ケースで93.4〜97.5%の便を担当しました。例外は90 kW冬で、燃料バス優先の解が安く、電気バスの担当は22%でした。
- 〔表3〕 **受電上限は高いほど安いわけではありません。** 総費用が最も小さいのは、春・夏は200 kW、冬は400 kWでした。900 kWは、どの季節でも最も高くなりました。
- 〔図4〕 内訳を見ると理由が分かります（車両使用費の402〜408万円/週は、ほぼ一定なので除いています）。
  - 基本料金は、90 kWの4.5万円から900 kWの44.7万円/週まで、上限に比例して増えます。
  - 電力量料金と燃料代は、上限が足りていればほとんど変わりません。
  - 上限が足りないと、別の費用が増えます。冬の200 kWでは超過の費用が26.7万円/週かかります。冬の90 kWでは燃料代が41.1万円/週に増えます。
- 補足：便割当は最適とは確かめられないので、「電気バス優先」と「燃料バス優先」の2通りから解き、安い方を採用しています。

### ⑤ 考察とまとめ（40秒）〔5．考察とまとめ、図5、図6〕

- **運用の目安（今回の条件）：** 受電上限は大きく取らず、充電の時間をずらして、冬にも超過が出ない400 kWに抑えるのがよいと考えます。
  - このとき電気バスは、全季節で93.7〜96.0%の便を担当できます。
  - 900 kWより約24.4万円/週安くなります（3季節の平均）。
  - 200 kWとの差は、ギャップ5%（約21万円/週）より小さく、どちらが安いとは言い切れません。
- 〔図5〕 計算は時間で打ち切っていますが、目的関数は打ち切る前にほぼ下げ止まっていました。
  - 便割当では、最後の30分の改善は0.11%以下でした。
  - 毎時の再計画で時間切れになった100回のうち、91回は240秒までに最終の解に達していました。
  - ただし、下限との差（ギャップ、中央値25%）は残っていて、最適とは言えません。
- 今後の課題は、基本料金と受電上限も一緒に最適化することです。
- 〔図6〕 今後の予定です。
  - 2027年3月：電気学会全国大会で発表
  - 2027年度：日をまたぐ計画と、蓄電池の最適化
  - 2028年2月（修士最終発表）：受電上限・蓄電池・充電器の決め方の指針

## 正直に言うこと（聞かれたら必ず）

- 数値はまだ**診断用**で、研究の結論には使っていません。
- 便割当は最適解と確かめられていません。また、便割当と充電の2段階で解いているので、全体としての最適解でもありません。
- 蓄電池は決めた規則で充放電していて、最適化していません。
- 200 kW夏の電気バス優先の計算は、1回目がメモリ上限（14 GiB）で止まりました。24 GiBで1回だけ計算し直しています。
- 毎時の再計画（174〜175回）では、最大44回が時間切れになりました。
- 超過の費用500円/kWhと、電力のCO₂係数0.5 kg/kWhは仮の値です。

## 想定質問と答え（短く）

| 質問 | 答え |
|---|---|
| なぜ900 kWが一番高いのか | 基本料金が受電上限に比例するからです。900 kWの基本料金は44.7万円/週で、400 kWより約25万円高くなります。電力量料金と燃料代は、ほとんど変わりません。 |
| 結局、受電上限は何kWがよいのか | 今回の条件では、冬にも超過が出ない400 kWが目安です。200 kWとの差はギャップの範囲内なので、どちらが安いとは言い切れません。 |
| 最適解なのか | 違います。ギャップ5%で打ち切っていて、2段階で解いているので全体の最適でもありません。図5のとおり、打ち切る前にほぼ下げ止まってはいます。 |
| 図5のギャップ25%とは | 毎時の再計画で時間切れになった回について、得られた解と下限の差の中央値です。解はほぼ下げ止まっていますが、最適だと証明はできていません。 |
| なぜ2通りの初期割当なのか | 時間内に最適と確かめられず、探索が最初の割当の近くにとどまりやすいからです。性質の違う2つから始めて、安い方を採っています。 |
| 受電上限を超えてよいのか | 上限は契約の目安として扱い、超えた分に500円/kWh（仮）をかけています。厳しい制約にすると、条件によっては解が見つからないためです。 |
| 基本料金を最適化に入れないのはなぜ | 受電上限 P はケースとして与えていて、基本料金は P だけで決まる定数だからです。P も一緒に決めることは今後の課題です。 |
| CO₂の費用を総費用に入れないのはなぜ | 1円/kgは仮の値なので、計画の重みとしてだけ使っています。CO₂は別に示しています。 |
| 秋がないのはなぜ（11/19 研究室の質問） | 秋は春と同じく中間の季節なので、今回は計算の量を抑えて冬・春・夏の3週にしました。ただ、秋は日射や祝日が春と違うので、今後は秋も加えます。 |
| 冬の方が太陽光で賄えるのか | 逆です。太陽光は夏が多く、冬は多く買います（400 kWで冬3,955 kWh、夏2,501 kWh/週）。費用の季節差はギャップより小さく、各季節1週ずつなので、統計的に有意とは言えません。 |
| 電気代の計算例は | 400 kW冬なら、3,955 kWh×17.43円で約6.9万円、基本料金 400×2,530×0.85×12/52 で約19.9万円、超過0円。合計は約26.7万円/週です。 |
