## 保管ルール

- 日付ごとのフォルダへ追加し、過去資料を上書きしない。
- `analysis/` は既存結果の再集計。新しい最適化実験とは数えない。
- 数字の正本は `docs/evidence/` と、そこに結び付いた凍結実行artifact。
- 発表資料には実験SHAと分析対象を明示する。9月5日の結果説明パッケージの実験SHAは `bb0c005`、資料作成時HEADは `c0b82ae3`。文献レビューは新しい実験ではない。
- 過去のPPT内の説明に新しい根拠が必要な場合、まず今回の発見メモを参照する。

次回も「今回確かめたこと／自分で説明できること／次に答える問い」を1件ずつ残す。
