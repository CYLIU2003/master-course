# 学内中間発表・学会発表の題目候補

作成：2026-10-05。ユーザーが今回明示した研究目的を優先し、Claude Code / Sonnet 5と検討。

**この文書は前案です。** 同日の追加指示「電気科なので経済性へ寄りすぎない題目」を反映した [Opus/highとの最新案](TITLE_CANDIDATES_ELECTRICAL.md) を現在の推奨とします。費用低減と補助金の研究目的は維持しています。

## 研究目的の整理

**平日・土休日を含む連続7日間の運行と充電が成立するかを示し、費用を抑える運用の評価を、電気バス・PVの導入経済性と必要な補助金水準の検討へつなげる。**

各月の代表週12本は、季節による運用・電力利用・費用の違いを見るための実験設計。研究を「12か月を計算したこと」や「厳密最適性の証明」に置き換えない。現結果は電費一定条件の月別代表週比較であり、気温・空調等を含む季節影響の全評価ではない。

## 1. 学内中間発表：研究全体の方向を示す

### 推奨題目

**太陽光発電を活用した電気バスの7日間運用と導入支援に向けた経済性評価**

副題を付ける場合：**―月別代表週の評価から補助金水準の検討へ―**

「7日間運用」で運行・充電の成立を、「導入支援に向けた」で補助金まで見据える目的を示す。中間発表では研究全体の題目とし、本文で運用費の評価まで完了、導入費・補助金の評価は今後の作業、と分ける。副題は将来への方向を示し、補助金額を算定済みとはしない。

短く、研究全体を広く表す代案：

**太陽光発電を活用した電気バスの週次運用と導入経済性に関する研究**

こちらでは「週次」が連続7日間であることを冒頭で明示する。

## 2. 学会発表：投稿時点で示せる成果を明確にする

### 現在の結果を基にした推奨題目

**太陽光発電を活用した電気バスの7日間運行・充電計画と運用費評価**

推奨する副題：**―12か月の代表週を用いた季節差の検討―**

運行・充電計画と7日間の費用評価を主題にし、副題で12代表週を計算した目的を示す。週内の状態継承と最終翌朝までの評価を本文で示す。各月の同じ長さの代表週の比較であり、月全体の請求額や1年間の連続運用ではない。

期間・比較設計を先に出す代案：

**月別代表週を用いた太陽光発電併用電気バスの7日間運用と費用評価**

学会原稿では、設定された運行・設備条件下の数値シミュレーションであること、実請求額とは異なる費用モデル、初終端在庫、実行可能解と最適性の範囲を示す。

## 3. 補助金評価まで完成した場合の題目候補

**太陽光発電併用電気バスの週次運用に基づく導入採算性と補助金水準の評価**

これは現時点の学会推奨題目ではなく、導入経済性の数値評価を実施した場合の候補。まず「事業者の導入採算に必要な支援水準」を検討する方針が、現在の運用計画とつながる。社会全体で最適な補助額を求めたという意味にはしない。

運用費だけから必要補助額は決まらない。車両・PVの導入費、保守・交換、評価期間、残存価値、比較する運用・設備、資金評価の条件を揃える。運用費の低減が必要支援額へどう反映されるかを評価し、「設備追加は必ず安くなる」「補助金を減らせる」と先に結論づけない。

## 4. 題目での言葉の選び方

| 表現 | 扱い |
|---|---|
| 7日間運用／運行・充電計画 | 主目的を表す。翌朝SOCと週内の状態継承は本文へ |
| 月別代表週／季節差の検討 | 12代表週の目的を表す。季節全体・年間の実績評価とはしない |
| 運用費評価 | 現在の費目別結果に対応。設備投資や補助金の完成まで含めない |
| 導入経済性／導入支援に向けた | 中間発表で研究全体の方向を示す。完了・未実施を本文で区別 |
| 最適化 | 手法を表す語として使用可能。大域最適性が未証明でも一律禁止しない |
| 最適運用／最適な補助金 | その最適性を示す根拠が必要。現推奨題目では使用しない |
| 実証 | 実営業所の試験を意味し得るため、現在の数値シミュレーションには使わない |

BESSや混成車両の詳細、分散PCの台数は本文へ置き、題目に全要素を詰め込まない。「太陽光発電」は、専門外の学内聴講者にも意味が分かるようPVより優先する。

## 5. Claudeとの検討と確認範囲

レビュー原文は [初回](claude_review.md)・[訂正後](claude_final_review.md)。Claudeへ確認済みの成果範囲とユーザーの目的を渡し、ツールなしで題目を検討した。原本の再検算・教員承認・学会の題目登録は行っていない。

初回の「実証的」という候補、最適性未証明を理由とする「最適化」の全面禁止、運用費差だけから補助金額を求められるような説明は訂正を依頼した。最終候補では、現在の結果と導入支援へ向けた研究目的を分けて表した。

再レビューで学会題目の情報量を抑える指摘があったため、主題は「7日間運行・充電計画と運用費評価」、副題は「12か月の代表週を用いた季節差の検討」に分けた。中間発表の副題は任意とし、未実施の補助金評価を本文でも明示する。
