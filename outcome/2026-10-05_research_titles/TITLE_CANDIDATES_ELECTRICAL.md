2026-10-05。前の経済性中心案に対するユーザーの修正を反映し、Claude Opus 5.5 / effort highと2回討論した題目案の履歴。

**後続の文献比較を反映した最新版は [TITLE_PROPOSALS.md](../2026-10-05_literature_novelty/TITLE_PROPOSALS.md)。** 本文は文献調査を拡充する前の検討として保持する。

## 推奨題目

### 学内中間発表

**太陽光発電を活用した電気バスの7日間運行・充電計画**

副題：**―運用成立性と電力利用の評価―**

運行時刻・回送・充電可能時間・翌朝SOCを満たす計画を作り、その計画で電力をどう使うかを評価する研究として示す。経済性を題目の先頭へ置かず、主目的の7日間運用を明示する。

### 学会発表

**太陽光発電を活用した電気バスの7日間運行・充電計画と電力利用の評価**

副題：**―月別代表週による季節差の検討―**

計画だけでなく、得られたPV利用・抑制・買電・SOC等の結果を評価したことを示す。副題の月別代表週は2025年の各月1週、計12週。四季4ケースや年間連続運用とはしない。

副題を使わず、制約と充電をより強調する代案：

**運行制約を考慮した太陽光発電併用電気バスの7日間充電計画**

この代案は充電が主題に見えるため、車両割当を含む研究全体には上の推奨案の方が合う。

## 1. この研究の電気工学上の中心

**バスの運行要求を満たしながら、時間とともに変わるPV、買電、蓄電池残量を用いて、7日間の充電をどう計画するか。**

具体的には次を対応づける。

- 運行・帰庫・回送と、充電器に接続できる時間。
- 翌朝までに必要な車両SOCと、日をまたぐ残存エネルギー。
- PV発電時刻と、バス充電・補助BESS充電・抑制の配分。
- BESS残量、買電電力量、受電電力の時間的な変化。

これは運行制約を持つ電力利用・エネルギー管理の数値シミュレーションである。題目を電気工学らしくするために、実施していない配電潮流、電圧・周波数制御、新しいEMS制御器、実機実証を付け加えない。

「受電電力」だけにすると、研究がピーク削減へ狭く見える。現在の成果はピーク削減の対照実験を証明したものではなく、PV・充電・SOCを含むので、推奨題目は「電力利用の評価」とする。

## 2. 経済性と補助金は研究内容に残す

題目の主役を変えても、ユーザーが目指す費用低減・導入経済性・補助金水準の検討は残す。

**運行・充電の成立 → 電力利用の評価 → 運用費低減の検討 → 導入採算と必要な支援水準の評価**

発表では運用費を電力・燃料・車両使用等へ分解し、どの電力利用・運行結果が費用へ対応するかを説明する。補助金は背景と今後の展望に置き、車両・PVの導入費、保守・交換、評価年数、残存価値、比較対象等を加えた評価へつなげる。補助金額や投資回収を既に算定したとはしない。

題目に経済性を入れないことと、費用低減を研究目的から除くことは異なる。電気工学上の計画・制約・電力利用を主題にし、その計画の導入上の意義を経済性で評価する構成である。

## 3. 題目と対応させる既存の図表

| 題目の要素 | 発表する内容 |
|---|---|
| 7日間の運行・充電計画 | 日別ダイヤ、全対象便、車両運用・充電時刻、日境界と最終翌朝の範囲 |
| 運用成立性 | 車両SOCと翌朝目標、充電器占有、帰庫・回送、保存済み物理確認 |
| 電力利用 | PV、買電、バス充電、BESS充放電・残量、抑制の時系列と電力量 |
| 季節差 | 同じ形式で並べた12代表週の電力利用・運行・費用と日射入力 |
| 経済性への接続 | 費目別運用評価額と電力量・受電電力・車両使用の対応 |

PV自家消費率などの比率は、計測境界・初期BESS在庫・損失・終端残量・分母を定義してから使う。まず原本から追跡できるPV直接利用、PV→BESS、抑制、買電を示す。

200 kWは超過モデル費のソフト閾値であり、実設備の受電上限ではない。電費は一定で気温・空調負荷は含まない。月別費用・電力差には気象・予測情報・配車と充電・探索到達度・在庫の違いも含む。季節差の記述比較をPV単独の因果効果と断定しない。

## 4. Opusとの討論で採用・訂正した点

原文：[初回討論](opus_round1.md)、[反論後の再討論](opus_round2.md)。設定と実モデル：[review_settings.json](review_settings.json)。

| 論点 | 討論と最終判断 |
|---|---|
| 経済性を主題から外すと研究の動機を失うか | 技術的な主題を運行・充電と電力利用へ置き、費用・補助金を評価と応用に残す |
| 受電電力を中心にする案 | Opus初回案へ、ピーク研究に狭く見えると反論。再討論で撤回され、「電力利用」を採用 |
| EMS研究には新しい制御器が必須という意見 | 一律には成立しないと反論。Opusが訂正。今回はEMSという広い語より、具体的な運行・充電計画を優先 |
| 「週次」という語は使えないという意見 | 一律禁止は採用しない。週次でも独立週は説明できるが、今回の題目は期間を明確にする「7日間」を選ぶ |
| 「電力利用特性」の表現 | 使用禁止とはしない。現在の成果範囲を直接表す「電力利用の評価」を選び、特定の新しい特性を発見したと先に主張しない |
| 「最適化」を使うか | 手法語として使用可能。題目は何を計画・評価するかを優先し、統合大域最適性未証明を理由とする語の一律禁止はしない |
| 季節差の源をPV・運行条件だけに限定する意見 | 原結果には探索・予測・在庫の違いもあるため、その限定は採用しない |

Claudeの回答をそのまま採用せず、ユーザーの目的・確認済み成果・題目の読みやすさへ照合した。原本再検算・教員の承認・投稿題目の登録を行ったものではない。
