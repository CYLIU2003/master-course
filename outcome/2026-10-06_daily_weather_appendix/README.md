# 各月代表週の日別天候・日射量一覧

2025年の12代表週について、84暦日の天候と日射量を資料末尾へ追加しました。

- [編集可能なPowerPoint](research_progress_20261006_daily_weather.pptx)：元の44枚に、月ごと7日分の一覧12枚を追加。最後の45〜56枚が新しい一覧です。
- [PDF](research_progress_20261006_daily_weather.pdf)：本文18枚と新しい一覧12枚、計30ページ。一覧は最後の19〜30ページです。従来の非表示補足26枚はPowerPoint内で保持しています。
- [日別原値CSV](daily_weather_84days.csv)：84日分。スライドでは小数第3位に丸め、CSVは丸め前の値を保持しています。

各表は日付・曜日、天候分類、日射量GHI、晴天比R、昼間降水量、全日降水量を記載します。日射量は**水平面の日積算値[kWh/m²/日]**で、発電量[kWh]とは別です。週の日射量合計は7暦日分を積算しています。計算期間末尾の翌朝区間を、8日目の天候として加えていません。

天候は保存済みSolcast履歴推定値による**研究用分類**です。気象庁の観測天気や、予報の的中実績ではありません。昼間（晴天時GHIが20 W/m²以上）の降水が1 mm以上なら雨、それ以外はRが0.7以上で晴れ、未満でくもり。Rは昼間の推定GHI積算を晴天時GHI積算で割った値です。雨の分類に晴れ間が含まれる場合があります。

**3月3日は未判定＊を保持**しています。低温降水から雨雪の区別が未確認のため、従来の天候クラス統計では除外されていますが、日射量と週次運用の対象には含みます。日射量を欠測やゼロへ置き換えていません。

出典は、9月28日資料に固定保存された `evidence/weather/weather_labels.csv` と、弦巻営業所の2025年Solcast原本12か月です。84日×96区間の8,064区間から、日射量・降水量・晴天比を再集計し、凍結済みの日別値・分類と一致することを確認しています。計算本体・入力・過去結果の判定は変更していません。研究計算の固定SHAは `f524eca2552a4386bd033a15bbe046c14dc09281` です。
