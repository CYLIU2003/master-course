# GXに向けた燃料バスと併用する電気バスの便割当・充電計画の最適化

研究の概要と今後の方向性について

2026年10月　東京都市大学 大学院 修士1年　劉 承洋

（スライド「西山先生へのご相談_研究の現状と軸C.pptx」と同じ内容）

## 1. 研究背景

- 脱炭素化に向けて路線バスの電動化が進む一方、車両価格や充電時間の制約から、当面は燃料（軽油）バスとの併用が続く。
- 電気バスは運行終了後、営業所で夜間にまとめて充電される。
- 多数の車両が同時に充電すると、営業所が電力会社から受け取る電力（受電電力）が大きくなり、受電設備の増強や電気料金の増加につながる。
- どの便を電気バスに任せ、いつ充電するかを工夫することで、この負担を抑えられる可能性がある。

## 2. 研究目的

燃料バスと電気バスを併用する営業所を対象に、便の割当と充電計画を数理最適化によって決め、受電電力の上限が電気バスの運用と費用に与える影響を明らかにする。

最適化で決めるもの：

- 各便を担当する車両（電気バス・燃料バス）
- 各電気バスの充電の時刻と量（15分刻み）
- 営業所の太陽光発電・蓄電池・買電の使い分け

時刻表どおり全便を運行し、電池残量と充電器台数（10基）の制約を守ったうえで、1週間の費用（車両使用費・電気代・燃料代・受電上限の超過分の費用）を最小化する。

## 3. 対象と計算条件

表1　計算条件（受電上限4段階 × 3週 ＝ 12ケース）

| 項目 | 内容 |
|---|---|
| 対象 | 東急バス 渋21〜23系統（弦巻営業所）、1週間 1,704便 |
| 車両 | 電気バス35台・燃料バス25台（保有台数は固定） |
| 営業所の設備 | 太陽光発電 1,000 kW、蓄電池 6,000 kWh、充電器 90 kW × 10基（いずれも設置を仮定） |
| 対象期間 | 2025年の冬（1/6〜）・春（4/7〜）・夏（7/7〜）の各1週間 |
| 受電上限 | 90／200／400／800 kWの4段階。超過した電力量には500円/kWhの費用を課す（仮の値） |
| 単価 | 電力量 30円/kWh、軽油 150円/L、車両使用費 2万円/台・日 |

## 4. 計算方法

- 数理最適化（混合整数計画法）を用いる。問題の規模が大きいため、2段階に分けて解く。
- 第1段階：便の割当を決める（どの便をどの車両が担当するか）。
- 第2段階：割当を固定し、15分ごとの充電と電力の使い分けを決める。
- 1時間ごとに、その時点の状態から残りの計画を立て直しながら1週間を運用し、その結果から費用を集計する。

求解にはGurobiを用い、第1段階には一部の便だけを解き直す近傍探索を併用した。

## 6. 結果　受電上限と電気バスの担当便・費用

- 受電上限を800 kWから90 kWまで下げても、電気バスの担当便は92.0〜96.5%でほぼ一定であった（図2、全1,704便に対する割合）。
- 費用（電気代・燃料代・上限超過分の費用。3週の平均、車両使用費を除く）は約11万円/週から約87万円/週に増加し、その大部分は上限超過分の費用であった（図3）。

条件は表1のとおり。

## 7. 考察と課題

- 燃料バスが担当したのは、主に早朝（5〜6時台、13〜24%）と深夜（22時以降、17〜22%）の便であり、日中は1〜5%にとどまった。この傾向は受電上限によらなかった。
- 受電上限を下げても燃料バスへの振替が増えなかったのは、第1段階（便の割当）で充電をすべて太陽光と蓄電池でまかなえると見込んでいたためと考えられる。実際の充電計画では、1週間に2,137〜4,236 kWhを買電していた。
- 現在、受電上限を超過できない条件での計算を行い、燃料バスへの振替が生じるかを確認している。
- 計算は時間で打ち切っており、最適性は確認できていない。また、超過分の費用（500円/kWh）と電力のCO₂排出係数（0.5 kg/kWh）は仮の値である。

## 8. 3本目の柱について

これまでは電力・費用の観点から検討してきたが、3本目の柱では、路線バスの運行や利用者の観点を取り入れたいと考えている。現時点の候補は次のとおりである。

1. ダイヤ変更と電動化：減便や増便をしたとき、電気バスで担当できる便・受電電力・費用・CO₂がどう変わるか
2. 車両の使い分け：低床の電気バスを高齢者や車いす利用の多い便に優先して割り当てたときの、費用や充電への影響
3. 非常時の電源としての活用：災害時に電気バスを避難所などの電源に回した場合に、翌日の運行と両立できる台数・電力量
4. 事業者・利用者の受け止め：最適化が示す運用（車両の入れ替えや充電のための待機など）に対する、事業者・利用者の評価
5. 電気料金・CO₂の時間変化：時間帯によって変わる電気料金やCO₂排出係数を考慮した充電計画

## 補足　用語

| 用語 | 意味 |
|---|---|
| 便 | バスが始発から終点まで1回運行すること |
| 営業所 | バスの車庫。電気バスはここで充電する |
| 受電電力 | 営業所が電力会社から受け取る電力。単位はkW |
| kW と kWh | kWはある時点の電力の大きさ、kWhは使用した電力量（kW × 時間） |
| 受電上限 | 受電電力の目安。本研究では、超過した電力量に費用を課している |
| 数理最適化 | 制約と費用を数式で表し、費用が最小となる計画を計算機で求める方法 |
