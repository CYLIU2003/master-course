# Claudeとの研究検討：提案の採否

2026-10-03。Claude Code / Sonnet 5のツールなし・読取り専用レビューを3回実施した。実応答の記録は `claude_round1.md`、`claude_round2.md`、`claude_round3.md` に保存。Claudeへは論点と確認済みの数値・文献概要を渡し、原本へのアクセス、求解、端末変更は与えていない。

## 検討の進め方

1. 先生の問いと現在の研究条件を渡し、研究目的、意味、少数の追加確認を検討。
2. 原本CSVから追加した4月・5月の差、5/12〜13の時系列、確認した先行研究を渡し、主張と証拠を照合。
3. 2回目までの過大な解釈・合意条件の変更を指摘し、BESS方策と12代表週を維持する方針へ訂正。

## 採用・訂正した点

| 提案・解釈 | 判断 | 理由と最終的な扱い |
|---|---|---|
| PV総量だけでなく、運行・充電要求との時間的な関係を研究の中心へ置く | 採用 | 4月と5月のPV総量差約1%と費用差約57.6万円、5月の夜間買電・翌日抑制が具体的な検討入口になる |
| 7日間計算・PV・季節比較をそのまま新規性にする | 訂正 | 確認した先行研究で扱われる。対象固有の運用条件で何を定量的に明らかにするかを貢献候補とする |
| 200 kWを設備の上限や実契約料金と説明する | 不採用 | 有料超過可能なモデル閾値。実設備定格・実請求規則は別 |
| 00〜06時の電力量確認を、帰庫から出庫までの不可行性証明とする | 不採用 | 時間窓と固定条件が異なる。実帰庫、前夜への移動、別配車を扱っていない |
| BESS終端を固定して全12週を再計算することを先に要求する | 不採用 | 追加予備・終端復元なしの合意条件を変更する。既存結果の分析と少数の必要比較を先行させる |
| BESS終端が毎週1,200 kWhとみなす | 訂正 | 原値は1,200〜2,498.60 kWh。ピーク時の下限と週終端を区別する |
| 在庫差を「前借り・返済」と表現する | 不採用 | 今回は有限期間の正味残量変化であり、補充時期・費用を確定したものではない。kWhで併記する |
| 年次の違いをそのまま予測誤差と呼ぶ | 訂正 | 予測誤差は予測系列と実現系列の差。2026ダイヤ×2025気象という仮想実験の年次説明とは別 |
| 固定配車で充電時刻を変え、改善余地を確認する | 採用 | まず1件、必要なら2件。情報・物理条件と比較内の初終端状態を揃える。運用改善と予知情報の診断を分ける |
| 設置面PVを別入力版として確認する | 採用 | DNI/DHI・太陽位置・角度を使う入力分析を先に実施する方針。実角度不明は仮定。旧結果へ上書きしない |
| 大域最適性の証明を実運用・成果提示の必須条件にする | 不採用 | 可行性・設備対応・運用安全性と最適性は別。実行可能解を正しく評価し、未証明範囲を示す |
| 記述的12週結果にも必ずH0検定を要求する | 不採用 | 選定代表週の記述比較に母集団推論のp値を付けない。因果効果や一般化を主張する追加設計とは分ける |

Claudeの第三稿でも「料金プラン」という表現や在庫の比喩は根拠以上に広い。そのまま採用せず、最終説明は原本のモデル定義へ戻した。

## 結論の責任と検証範囲

Claudeとの合意自体は、科学的な証拠でも先生の承認でもない。採用した論点をCodex側で原本・数値・一次資料へ照合し、未検証の仮説を区別した。数値分析・図・研究説明が今回の成果であり、正式研究採用の判定は変更していない。

原レビュー文には訂正前の提案も残す。最終方針は [研究の意味と先生への説明](RESEARCH_MEANING_AND_TEACHER_RESPONSE.md) を参照する。
