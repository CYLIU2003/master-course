## このドキュメントの目的

本研究では、東急バスの BEV（電気バス）/ICE（エンジンバス）混成車両群を対象に、
便割当と、充電・PV・BESS・系統電力の運用可能性を MILP で評価します。現行の研究結果は
**Phase 3（二段階最適化）**であり、便割当と電力調達を一つの目的関数で同時最適化した
大域最適解ではありません。

このファイルでは以下を説明します。

1. 研究として何を解こうとしているか
2. どこまで実装できているか（定式と実装の対応）
3. 先生にレビューしていただきたい観点
4. 重要ファイルへの案内

## 1. 研究概要（3行で）

| 項目 | 内容 |
|------|------|
| **対象** | 東急バス全営業所の BEV/ICE 混成車両群 |
| **決定内容** | Stage 1: 便割当、Stage 2: 固定割当下の充電・電力調達（系統/PV/BESS） |
| **最小化** | Stage 1: ICE燃料・CO₂・車両使用費 + 天候別の集約充電費用下界、Stage 2: 電力・需要・電力由来CO₂費等 |

> [!IMPORTANT]
> Phase 3の費用は、可行スケジュールの会計比較には使用できますが、BEV/ICE比率を含む
> global total-cost optimumとは主張できません。便割当とエネルギー運用の同時最適化は
> Phase 4の研究課題として区別します。

                            ↓
          ┌─────────────────────────────────────────────┐
          │           MILP 最適化モデル（Gurobi）          │
          │                                               │
          │  決定変数                                      │

          │                                               │
          │  制約（C1〜C21）                               │

## 3. 目的関数の説明

### 3.1 現行Phase 3の目的関数分離

現行Phase 3は、次の二段階です。

1. Stage 1が、全便運行・接続・車両・楽観的SOC必要条件の下で便割当を決める。目的関数はICE燃料・CO₂・車両使用費に加え、便割当から求めた充電必要量を営業所別に集約し、PV、初期BESS余剰、系統電力の順に費用配分する**天候別の集約充電費用下界**を含む。
2. Stage 2が、Stage 1の割当を固定して、SOC・充電器・契約電力・PV・BESSを満たす充電と電力調達を決める。

Stage 1の充電費用下界は、フロント設定のPV限界費用（現比較では0 JPY/kWh）と
天候別PV発電可能量を割当探索へ伝えるための代理項である。便・始発回送・便間回送・帰庫回送、
初期SOC、実効終端SOC要求を含む一方、充電時刻、充電器競合、契約電力、需要料金、
PV/BESSの時刻整合は含まない。これらはStage 2でのみ厳密に検証する。そのため代理値を
実現電気料金又は総費用として報告しない。

用語を数式で書くと、EV外部充電量の下界は
`max(走行・回送消費 + 終端要求SOC − 初期EV SOC, 0) / 充電効率`である。
ここでいう「下界」は、時間帯と設備制約を外した最低充電器入力であって、実際の充電スケジュールではない。
また、初期BESSから使える日量代理は
`max(初期BESS SOC − 終端要求SOC, 0) × 放電効率`である。現行晴雨比較では
初期・終端がともに300 kWhのため0 kWhとなる。PV控除も日量集約値であり、実際のPV→busフローはStage 2の結果だけを用いる。

### 3.2 日次計画と毎時再最適化

計算時間短縮は、日次のStage 1を極端に短くして割当品質を落とす方法ではなく、次の運用階層で行う。

1. 日初にPhase 3を解き、当日のBEV/ICE便割当を確定する。
2. 毎正時に、割当を固定したまま実測EV SOC、実測BESS SOC、既発生需要ピークを与え、当日末までの充電・PV・BESS・系統運用だけを再最適化する。
3. 得られた計画の先頭60分だけを実行し、次の正時に更新する。

1500秒日次runの実測は晴天775.530秒、雨天776.519秒だった。Stage 1/2を120/30秒へ短縮すると
Stage 1 gapが100%で晴雨とも同じ粗い割当となったため、研究用比較には採用しない。一方、確定割当下の
入力・接続契約確認後の5:00時点再最適化は晴天1.964秒、雨天2.021秒（MILP solve約0.06秒）でoptimalとなり、終端300 kWh条件では
元の日次Stage 2結果を再現した。5:00結果のEV/BESS SOCと既発生需要ピークを6:00へ引き継いだ再計算も、
晴天2.032秒、雨天2.006秒でStage 2 optimal、264便・独立制約違反0となった。24時刻すべての連鎖は未検証である。
これは中野ほか（2025）の逐次計画原理を1時間更新へ適用した実装であり、
同文献と同じ予測時間幅・更新時間幅ではない。

BESS終端SOCは設備上必ず初期値へ戻す条件ではない。営業所設備画面では、(1) 運用範囲と終端下限のみ、
(2) 初期SOCへ戻す、(3) 任意の終端SOC目標、の3方針を選択できる。現行の暫定晴雨成果物は日間の在庫持ち出しを
同じにするため300 kWhへ戻す条件である。運用範囲だけを課す単日結果は翌日のエネルギー価値を含まないため、
初期値へ戻すケースと費用だけを直接比較しない。数理的な意味は
`docs/notes/phase3_literature_and_two_level_optimization_20260716.md`、手動計算と受理条件は
`docs/notes/phase3_manual_validation_runbook_20260716.md`に示す。

したがって「ICE燃料費と実電力費を一つの式で比較して最適BEV/ICE比率を決めた」という説明は、
現行Phase 3には適用しません。以下の統合目的関数はPhase 4の定式化目標・参照式として扱います。

### 3.3 統合モデルで最小化する式（Phase 4参照）

$$
\min \quad C_{total} = \underbrace{O1 + O2 + O3 + O4}_{\text{常に有効}} + \underbrace{\sum_j \pi \cdot u_j}_{\text{欠便ペナルティ（常に有効）}} + \underbrace{C_{CO_2}^{*} + C_{degr}^{*}}_{\text{パラメータ設定時のみ有効}}
$$

各項の展開：

$$
O1 = c_f \sum_{k \in \text{ICE}} \bigl( \sum_j f_k(j) y_j^k + \sum_{(i,j)} f_k^{dh}(i,j) x_{ij}^k \bigr), \quad
O2 = \sum_t p_t^{grid} \cdot g_t
$$

$$
O3 = p^{dem,on} W^{on} + p^{dem,off} W^{off}, \quad
O4 = \sum_k c_k^{veh} z_k
$$

$$
C_{CO_2}^{*} = p^{CO_2} \Bigl( \alpha_{ICE} \sum_{k \in \text{ICE},j} f_k(j) y_j^k + \alpha_{grid} \sum_t g_t \Bigr) \quad (p^{CO_2} > 0\text{ のとき有効})
$$

$$
C_{degr}^{*} = w^{degr} \sum_{k \in \text{BEV},t} \frac{c_{k,t} \cdot \Delta t}{cap_k} \beta \quad (w^{degr} > 0\text{ のとき有効})
$$

#### 各項の有効化条件

| 費目 | 有効化条件 | 備考 |
|------|-----------|------|
| O1 ICE 燃料費 | **常に有効** | ICE 車両が 0 台なら値が 0 になるだけ |
| O2 電気代（TOU） | **常に有効** | 系統買電量が 0 なら値が 0 になるだけ |
| O3 デマンド料金 | **常に有効** | 単価パラメータを 0 にすれば実質無効化可 |
| O4 車両固定費 | **常に有効** | 固定費パラメータを 0 にすれば実質無効化可 |
| 欠便ペナルティ | **常に有効・無条件** | コード上ですべての費目の後に無条件加算。最低 10,000 円/便 |
| CO₂ 費用 | `co2_price_per_kg > 0` のときのみ | デフォルト 0（無効） |
| 電池劣化費 | `degradation_weight > 0` のときのみ | デフォルト 0（無効） |

#### 変数の定義

**決定変数（ソルバーが値を決める）：**

| 記号 | 意味 | 型・範囲 |
|------|------|---------|
| $y_j^k$ | 車両 $k$ が便 $j$ を担当するか | 0/1 整数 |
| $x_{ij}^k$ | 車両 $k$ が便 $i$ → $j$ の回送接続をするか | 0/1 整数 |
| $u_j$ | 便 $j$ が担当不能（欠便）か | 0/1 整数 |
| $z_k$ | 車両 $k$ が 1 日に使われるか | 0/1 整数 |
| $c_{k,t}$ | 車両 $k$ のスロット $t$ での充電電力 | 連続 $[0, c_{\max,k}]$（kW） |
| $g_t$ | スロット $t$ での系統買電量 | 連続 $\geq 0$（kWh） |
| $W^{on}$ | オンピーク期間の最大需要電力 | 連続 $\geq 0$（kW） |
| $W^{off}$ | オフピーク期間の最大需要電力 | 連続 $\geq 0$（kW） |

**パラメータ（入力として与えられる定数）：**

| 記号 | 意味 | 単位 |
|------|------|------|
| $c_f$ | 軽油単価 | 円/L |
| $f_k(j)$ | 便 $j$ の燃料消費量 | L |
| $f_k^{dh}(i,j)$ | 回送走行の燃料消費量 | L |
| $p_t^{grid}$ | スロット $t$ の電力単価（TOU） | 円/kWh |
| $p^{dem,on/off}$ | オン・オフピークのデマンド単価 | 円/kW |
| $c_k^{veh}$ | 車両 $k$ の日割り固定費 | 円/日 |
| $\pi$ | 欠便ペナルティ単価（最低 10,000） | 円/便 |
| $p^{CO_2}$ | CO₂ 価格（デフォルト 0） | 円/kg |
| $\alpha_{ICE}$ | 軽油の CO₂ 排出係数（既定 2.64） | kg/L |
| $\alpha_{grid}$ | 系統電力の CO₂ 排出係数 | kg/kWh |
| $w^{degr}$ | 劣化費の重み（デフォルト 0） | 無次元 |
| $\beta$ | 1 サイクル当たり劣化コスト（現在 50.0 固定） | 円/cycle |
| $cap_k$ | バッテリー容量（既定 300） | kWh |
| $\Delta t$ | 1 時間スロットの幅 | h |

### 3.3 各費目の直感的な意味

| 費目 | なぜ最小化に含めるか | 組み合わせることの意義 |
|------|-------------------|--------------------|
| **O1 ICE 燃料費** | ICE バスの走行コスト | O2 と合わせることで「ICE ↔ BEV の最適混合比率」が決まる |
| **O2 電気代（TOU）** | 充電時刻をずらすと安い時間帯に充電でき、コストが下がる | O1 と合わせることで「充電量を無制限に増やすのではなく必要量だけ充電する」誘因が働く |
| **O3 デマンド料金** | 月の最大需要電力 × 単価が基本料金となる。充電を分散させると削減できる | ピーク充電の抑制・分散化を誘導する |
| **O4 固定費** | 使用台数が多いほど高くなる日割り固定費 | 必要最小台数で運用する方向に働く |
| **欠便ペナルティ** | 担当不能な便を実質的に禁止するための大きな罰則（通常 10,000 円/便） | — |
| **CO₂費（オプション）** | 排出量に価格を付け、CO₂ の少ない車種・充電時間帯を誘導する | `co2_price_per_kg > 0` に設定すると有効化 |
| **劣化費（オプション）** | 充電量が多いほど電池が劣化する。過充電を抑制する | `degradation_weight > 0` に設定すると有効化 |

### 3.4 デフォルト設定について

CO₂費・劣化費は `co2_price_per_kg = 0`（無効）がデフォルトです。
パラメータに正の値を設定すると目的関数に加算されます。
これにより、単純コスト最小化 / CO₂考慮 / 劣化考慮 を切り替えられます。

## 8. 用語対応表

数理最適化に慣れていない方向けに、用語を整理します。

| 数理用語 | 直感的な意味 |
|---------|------------|
| 目的関数 | モデルが最終的に一番小さくしたい「合計費用の計算式」 |
| 制約 | 現実の運行で絶対に破ってはいけない条件 |
| 決定変数 | モデルが自動で決める項目（便割当・充電量など） |
| MILP | 整数変数（0 or 1）と連続変数が混在する線形最適化問題の総称 |
| SOC | バッテリー残量（State of Charge）。ここでは kWh 単位 |
| TOU | 時間帯別料金（Time of Use）。電気代が時間帯によって異なる料金体系 |
| デマンド料金 | 月の最大需要電力（ピーク電力）に応じた基本料金 |
| ALNS | 適応型大規模近傍探索（近似解法。大規模問題向け） |
| deadhead | バスが乗客なしで移動すること（回送） |
| feasible connection | 時刻的に接続可能な便の組み合わせ |
