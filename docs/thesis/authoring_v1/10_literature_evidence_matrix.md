# 先行研究エビデンスマトリクス

正本は [`10_literature_evidence_matrix.csv`](10_literature_evidence_matrix.csv) である。手元PDFを実際に開き、少なくとも表題、著者、掲載先、年、DOIまたは資料種別、abstract/冒頭の研究範囲を確認した。ファイルhashは `evidence_supplements/literature_source_hashes.csv` に固定した。

## 位置付け

既往研究は、(i) 車両運用と充電の共同最適化、(ii) PV・BESSを含むエネルギー管理、(iii) 消費電力量・予測誤差・電池劣化の扱い、(iv) 国内運行を前提とした充電需要・逐次計画へ分類できる。本研究は、混合BEV/ICEの便割当候補、PV・BESS・系統・燃料の会計、15分内部刻み、24回のRolling、独立物理検算を一つの証拠鎖へ接続する点に実装上の特徴がある。

ただし、現行Phase 3は統合大域最適化ではない。先行研究の統合モデルに対して優越を主張するのではなく、実データ契約、物理検算、rolling実行、会計整合性を分離してfail-closedに監査する研究設計として差分を述べる。

## 未充足の比較軸

電池劣化、予測誤差、確率・頑健最適化、設備投資、LCC、複数営業所、複数季節は未検証である。これらは既往研究が示す重要軸だが、今回の凍結結果から追加主張してはならない。
