# 結果分析

## 正当性

SUNNYとRAINはともに264/264便を担当し、未担当0、独立物理検算VALID、24/24 Rolling accepted、会計eligibleである。正本実験SHAはcleanな`bb0c005...`であり、比較固定hashは一致し、PV hashだけが異なる。したがって、以下は実行可能な有限候補比較として使用できる。

## 配車

| 指標 | SUNNY | RAIN | RAIN-SUNNY |
| --- | ---: | ---: | ---: |
| 使用BEV | 28 | 21 | -7 |
| 使用ICE | 4 | 11 | +7 |
| BEV担当便 | 199 | 91 | -108 |
| ICE担当便 | 65 | 173 | +108 |
| 総使用車両 | 32 | 32 | 0 |

使用総台数が同じなのは、車両使用費が32台×20,000円で共通となる一方、候補内でBEV/ICE構成と担当便が入れ替わったことを意味する。配車hashも異なるため、単なる電力recourse差ではない。

## 評価額と帳尻

本モデルの費用定義に基づく24時間Rolling実行日評価額はSUNNY 660,983.783805円、RAIN 698,598.628643円である。差額37,614.844839円は次の和である。

| 成分 | RAIN-SUNNY [円] |
| --- | ---: |
| 燃料費 | +33,054.032190 |
| 系統電力費 | +3,925.558300 |
| CO2費用 | +635.254349 |
| 車両使用費 | 0.000000 |
| 合計 | +37,614.844839 |

差額の87.9%は燃料費、10.4%は電力費、1.7%はCO2費用である。設備費や劣化費を含まないため、経済性の結論ではない。

SUNNYのday-ahead選択費とRolling評価額は同じ660,983.783805円であった。RAINはday-ahead 698,296.465284円、Rolling 698,598.628643円で、Rolling後が302.163359円高い。候補選択に使うday-ahead costと最終報告のRolling costを分ける必要がある。

PV利用率$(PV2Bus+PV2B)/PV$はSUNNY 44.30%、RAIN 100.00%、抑制率は55.70%と0.00%である。BESS初期・終端は両ケース3,000 kWhであり、$B2Bus=PV2B\times0.95^2$が成立する。RAINのbus向け供給に占める直接系統購入は約12.43%である。

SUNNYでPV抑制が多いのは、PV定格1 MWに対して受電・充電・BESSの時刻別吸収能力と、BEV配車に伴う充電需要時刻が一致しないためである。日合計PVが多いだけでは全量を利用できない。

## 22候補分析

- 候補の使用BEV範囲は14～35台、BEV担当便範囲は46～199便である。
- SUNNY/RAIN費用順位のSpearman相関は0.784であり、全体傾向は共通するが上位順位は入れ替わる。
- SUNNY選択候補は28 BEV・199 BEV便で、2位との差は5,180.298562円である。
- RAIN選択候補は21 BEV・91 BEV便で、2位との差は566.622470円である。
- 選択BEV台数は14～35台の範囲端ではない。ただし候補生成自体が全配車空間を覆う証拠ではない。
- 使用BEV台数と費用のPearson相関はSUNNY 0.782、RAIN 0.822であるが、29台以上の一部候補は総使用車両数も大きい。単変量の因果効果と解釈しない。
- BEV担当便数と費用の相関はSUNNY -0.562、RAIN -0.501であり、BEV便増加が費用低下と関連するが、候補構成の交絡を含む。

RAINの上位差が566.6円と小さいため、候補集合や近似Stage 1の変化で選択が変わる可能性を無視できない。22候補で結論が安定したとは主張しない。

## 96スロット

両ケースで`FOUND_AND_VERIFIED`である。各24 stepの実行prefixを連結したhashはSUNNY `162f3ab9...`、RAIN `8de0222f...`で、公開会計と一致した。missing/duplicateは0であり、PV、grid、BESS日合計、peak、終端SOCも1e-6以内で一致した。図は`figures/*executed*`および比較図、元データは`evidence_supplements/*96_slot*.csv`に置く。

## gapと計算時間

Stage 1 certified gapはSUNNY 9.5213476%、RAIN 1.6563581%、solve timeは約380.98秒と380.02秒である。これはStage 1近似目的のgapであり、Rolling評価額の9.52%/1.66%保証ではない。両ケース1%以内でもなく、統合問題の最適性は評価していない。

## 最小SOC

正本のminimum recorded BEV SOCは68.91 kWhであるが、全BEVの初期状態を含む。使用BEVの運行中安全余裕を表す指標として利用しない。
