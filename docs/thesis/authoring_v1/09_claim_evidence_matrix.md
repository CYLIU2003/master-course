# 主張–証拠マトリクス

正本は [`09_claim_evidence_matrix.csv`](09_claim_evidence_matrix.csv) である。各主張は、直接値、正確な再集計、またはローカル正本runからのhash検証済み再構成のいずれかに限定した。

## 判定の読み方

- `SUPPORTED`: 指定した範囲では正本証拠が直接支持する。
- `SUPPORTED_LOCAL_CANONICAL`: ローカル正本runまで含めれば支持するが、Git管理済みbundleだけでは再生成できない。
- `SUPPORTED_WITH_LIMITATION`: 数値は支持されるが、gapや候補範囲など解釈上の制限が重要である。

## 論文での中心主張

本研究が支持するのは、固定されたSUNNY/RAINの2入力に対し、有限22候補から選択されたPhase 3二段階解が、264便割当、物理検算、24/24 Rolling、会計検算を通過したことである。RAINではSUNNYよりPV利用可能量が小さく、BEV担当便が減り、燃料費を中心に評価額が増えた。ただしこれは2ケースの固定入力反実仮想比較であり、一般の雨天効果でも統合大域最適性でもない。

## 明示的に禁止する拡張

Stage 1のgapをStage 2総費用の最適性保証へ読み替えない。会計済み評価額を実支出、LCC、導入採算へ読み替えない。候補集合内の最小値を全実行可能領域の最適値へ読み替えない。2日比較を気象母集団の統計推定へ読み替えない。
