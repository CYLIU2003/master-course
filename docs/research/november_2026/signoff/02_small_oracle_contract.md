# Small-oracle contract

One Fresh Prepared ID is shared by RAIN 8, 12, and 24-trip cases. Each trip count runs in an independent process and contains a Phase 3 aligned subset reference plus a scalar exact Phase 4 reference. The comparison name is `phase3_aligned_subset_to_scalar_integrated_reference_distance`.

Exact eligibility requires all trips, validation PASS, complete used-BEV SOC traces, balanced energy inventory, all 12 finite accounting components, residual <=1e-6 JPY, Phase 4 OPTIMAL with zero gap or a valid exact certificate, and actual-cost objective semantics. It is not a decomposition gap or a 264-trip approximation guarantee.
