# Negative-result wording

- Evidence incomplete: “The frozen artifact generated and evaluated the reported assignments, but did not persist every candidate-level formal gate; candidate-set stability was therefore not evaluated.”
- Profile instability: “Within the four preregistered profiles, the selected physical assignment or practical-equivalence condition changed.”
- Exact reference failure: “The bounded exact-reference gate did not pass; no reference-distance result is reported.”
- Interrupted: “Execution stopped under the preregistered stop rule; completed artifacts are retained as diagnostic only.”
