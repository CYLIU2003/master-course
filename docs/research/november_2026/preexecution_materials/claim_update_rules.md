# Claim update rules

1. Replace NOT RUN only from immutable signed-family result JSON.
2. Correctness gates precede every numerical comparison.
3. A time-limit incumbent is feasible evidence, not optimality evidence.
4. Oracle claims remain limited to deterministic 8/12/24-trip subsets.
5. RAIN stability remains limited to four v3 profiles and requires complete candidate-level evidence plus the preregistered threshold.
6. Missing, rejected, or interrupted cases remain visible and are never imputed.
