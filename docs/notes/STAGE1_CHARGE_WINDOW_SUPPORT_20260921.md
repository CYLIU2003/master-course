## 次の変更と数学的な範囲

既存のStage 1は、ある開始・終了・便間接続を選択したときの充電可能区間を、
各15分slotの制約へ繰り返し列挙している。完全な候補接続は維持し、この繰返しだけを
端点の差分による連続状態へ置き換えるopt-in実装を追加した。

元の充電可能量の上界を `S[t] = Σ c[t,j] x[j]` とする。
`d[t,j] = c[t,j] - c[t-1,j]`、`S[-1]=0` と定義すると、
`S[t] = S[t-1] + Σ d[t,j] x[j]` で同じ値を表せる。
長い連続区間は開始・終了にだけ係数が現れる。
集合に穴がある場合や同じ機会が重複する場合も、元の係数の個数を保つ。
slotが連番でない場合も、元の有効slotの順序で同じ係数を再現する。

新状態に1などの上界を追加しない。元の非負の機会の和なので下界0だけを持ち、
充電可否の既存 `[0,1]` 上限はそのまま。元の係数が非負であることから、
整数解だけでなく分数割当にも同じ射影を持つ拡張定式化である。
既存の因子化接続のsupportは既に端点で表現されており、そのまま加算する。
料金・目的関数・SOC・回送時間・車両・operator・距離・時刻表・候補接続は変更しない。
既定動作は旧方式のままで、`stage1_sparse_charge_window_support=true` の診断だけで使う。

変更経路: `run_stage1_root_search_diagnosis` → 新規Prepare/検査 → `solve_week` →
`GurobiMILPAdapter._add_stage1_time_indexed_soc_relaxation` → Stage1 → Stage2 →
独立物理検証 → quality/summary。supportの出現数・端点数、nativeモデルサイズとメモリを記録する。
