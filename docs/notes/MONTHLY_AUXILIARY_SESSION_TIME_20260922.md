## 修正の数学的範囲

Stage1の充電稼働率u、開始a、終了bを0～1の連続変数とし、
`a[t] >= u[t] - u[t-1]`、`b[t] >= u[t] - u[t+1]`、
`p[t] Δt <= P (Δt u[t] - setup a[t] - teardown b[t])` を追加。
週の両端の外側は停止状態。Stage2の整数セッションは必ずこれを満たすので、
追加は必要条件の強化であり、物理的に成立する充電案を除く意図はない。
余計な整数変数は増やさず、1車両672区間あたり連続変数1344・制約2016を追加。

Stage1の窓の近似、SOC依存の充電速度低下、整数の最小セッション時間等は依然として緩和されている。
実車イベントの完全在庫計算では今回の案がさらに厳しくなるため、5.23kWhを唯一の不足量とはしない。
Stage1通過はStage2・週間物理検証通過を意味しない。統合総費用最適性は未証明。
BESSの補助方針、20～80%・PVバス優先・余剰蓄電・追加予備/復元なし、ダイヤ・車両SOC・会計は維持。
Stage1 1800秒/Stage2 120秒/主wall2400秒/毎時15秒、4threads、soft18GB、gap1%、seed42も維持。
