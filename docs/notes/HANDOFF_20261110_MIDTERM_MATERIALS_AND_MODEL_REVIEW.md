## 2. 計算の現状（2026-11-10 夜）

- 対象は柱A：受電上限 90・200・400・900 kW × 冬・春・夏 の12ケース。各ケースを電気バス寄り・燃料バス寄りの2つの出発点から解き、総費用（燃料は使った分）の安い方を採る。
- 2つの出発点がそろったのは24件中23件（12ケース中11ケース）。
- 残りは 900 kW夏・電気バス寄り。rc36 で2回計算し、2回とも毎時の立て直しで実行不能になり失敗した（`a900u` は76回目、`a900v` は97回目）。2026-11-11 01:31 に3回目として `a900w`（matlab-desktop）と `a900x`（pslab-mouse）を同じ条件で同時に出した（両方終われば `a900w` を結果とする。失敗した回はすべて残す）。原因は未特定（§5 の項目6）。資料とポスターでは「未完」と表示している。
- 版は rc33（7dc38d95）・rc35（9a0fe044）・rc36（375dd6f2）が混在している。資料とポスターには版を明記してある。
- 計算の正しい出し方：operation の json → `prepare_ahead.py` → `make_rc14p_batches.py` → `batch.json` で台を固定 → `keepalive_check.ps1`。`weekly_operator.py run` は seed と overrides を落とすので使わない。
- 詳しい経緯は `DEVELOPMENT_NOTES.md` の「rc36 の最初の結果（2026-11-10）」ほか。

主な結果（最新版、安い方の出発点）：

- 受電上限 900 kW・冬：電気バス中心が燃料バス中心より 19.8万円/週安く、CO₂は58%少ない。
- 燃料バス寄りが安いのは 90 kW冬・90 kW春・200 kW冬の3ケース。CO₂は11ケースすべてで電気バス寄りが少ない。
- 90 kW冬で CO₂ を1 kg減らす費用は約96円。
- 90 kW冬・電気バス寄りの超過（1,291 kWh/週）の9割は、曇りの月曜の翌未明（蓄電池が空の時間）に出る。

## 4. 発表で先に言うこと（主張の範囲）

- 「最適解を得た」とは言わない。便割当はメモリ上限で止まり、2段階法なので全体の最適でもない。
- 言えるのは次の3点。
  1. 受電上限が電化の損得を分ける境目を、2つの出発点のどちらから解いても同じ向きかで確かめた。
  2. 費用と CO₂ の兼ね合いを円/kgで示した。
  3. 超過がいつ・なぜ出るかを、実行の記録から突き止めた。
- 「出発点で答えが変わるなら最適化と言えるのか」と聞かれたら、上の1のとおり、検証の手段として2通りから解いていると答える。
