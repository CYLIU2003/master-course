# 選択週の日射量と月全体の比較

月別12週の選択規則と対象日は変更せず、選んだ週がその月の日射資源をどの程度表しているかを事後確認した。対象は弦巻地点の2025年Solcast履歴推定GHI、35,040個の15分区間・365日。各日96区間の連続性・原本hash・有限非負値を検証した。

日積算日射量は各区間のGHI［W/m²］×0.25時間÷1,000の合計。週と月で日数が異なるため、一日当たり平均［kWh/m²/日］で比較する。差は「選択週の日平均÷月全体の日平均−1」。月全体には選択週の7日も含まれる。

| 2月 | 02-03〜02-09 | 3.587 | 4.091 | -12.3% |
| 3月 | 03-03〜03-09 | 2.497 | 3.851 | -35.2% |

| 11月 | 11-10〜11-16 | 2.663 | 2.723 | -2.2% |
| 12月 | 12-01〜12-07 | 2.621 | 2.447 | +7.1% |

選んだ3月の週は月全体より日平均日射量が35.2%少なく、10月の週は20.2%多い。曜日構成と営業便数を揃えても、選んだ週の天候が月全体を代表するとは限らない。最適化結果は当該週の事例として解釈し、月平均や年平均の費用へそのまま外挿しない。

これは日射入力の記述的検査であり、PV発電電力量・充電需要・最適化費用の結果ではない。予測モデルの学習や計画へ2025年の将来実績を追加していない。日射と費用の関連は全12週の完走結果を揃えてから確認し、因果効果や統計的な季節一般化は主張しない。
