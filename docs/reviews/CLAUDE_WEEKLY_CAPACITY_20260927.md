# 決定メモ(第2版・訂正反映)

## 前回主張の撤回

1. **「全CPU予約・スレッド調整余地なし」は撤回**。`resource_fit`は`cpu_threads`を最優先で読み、現行マニフェストは明示的に`cpu_threads=4, minimum_ram_gb=16, task_memory_budget_gib=16`を設定。threads=cores自動フォールバックは`0/missing`時のみ発生。全稼働ワーカーslots=1。よってGurobiシングルスレッド固定という主張は誤りで、月次の順次時間依存性と混同していた。
2. **「history gatingが壊れている」は撤回**。`source_digest`は`bff/`と`src/`配下の`.py`のみをハッシュ化し、PVやタイムテーブルデータは対象外。固定12週が同一digest(`3eee18d7`)なのは仕様上当然であり、他の鍵フィールドでワークロードが区別される可能性が残るため、gating破損は未証明。
3. **「10/12週検証済み」は撤回、9/12が正**。1月の物理/会計証拠と5件の復元図は存在するが、週次コレクタ/完全レポート監査は未承認。11月・12月は転送/突合待ちではなく、依然として時間毎ソルブを実行中。RUNNING中のLOSTは意図的保持であり異常ではない。
